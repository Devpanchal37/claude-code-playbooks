# Image & Asset List

> Auto-maintained by the `ui-reviewer` agent during each review pass.
> **User action required:** Add each PENDING asset to the `assets/` folder, then update status to ADDED.
> Module will not be marked DONE until all assets for that module are ADDED.

---

## How to Use

1. After each UI review pass, this file is updated automatically
2. Review the PENDING items below
3. Add the asset file at the specified path under `assets/`
4. Change status from `PENDING` → `ADDED`
5. Notify Claude when done so the module can be closed

---

## Asset Status Key

| Status | Meaning |
|--------|---------|
| `PENDING` | Asset needed, not yet added by user |
| `ADDED` | Asset confirmed added to assets/ folder |
| `OPTIONAL` | Nice-to-have, not blocking |
